## Цель RC1

Сделать состояние проекта, при котором:

- не стыдно показать близким друзьям («кентам»);
- крипто-чат **реально** работает через живые сервера;
- можно провести полноценный end-to-end тест на двух устройствах;
- всё, что ещё симулируется, честно помечено.

Мы **не** делаем до RC1 идеальный продукт навсегда.  
Мы делаем состояние, в котором уже не стыдно и уже можно жить.

---

## Definition of Done для RC1

RC1 считается достигнутым, когда выполнены **все** пункты:

1. Два реальных Android-устройства могут найти друг друга и обменяться сообщениями через **живой** транспорт.
2. Сообщения шифруются Double Ratchet + настоящие Ed25519/X25519 identity keys.
3. В конфигах прописаны **рабочие** сервера (не localhost и не заглушки).
4. Пакетное имя больше не `com.example` / `aistudio...`.
5. В UI и в коде нет немаркированных симуляций критического контура (чат, ключи, транспорт).
6. Есть простой, понятный сценарий тестирования «из коробки» для друзей.

## План по фазам

### Фаза 0. Наведение порядка
**Цель:** чистый фундамент.

- Сменить `applicationId` и `namespace` на нормальное имя  
  (предложение: `org.madgammon.app` или `net.nexxus.madgammon` — выбери то, что тебе больше нравится, и скажи).
- Обновить `SIMULATION_AUDIT.md`.
- Создать в корне `RC1_CHECKLIST.md` с чекбоксами из Definition of Done.
- Зафиксировать текущую версию как `0.2.4` и начать ветку `0.3.0-rc1-dev`.

**Критерий:** проект собирается, запускается, package name красивый.

---

### Фаза 1. Живой транспорт сообщений (главный приоритет)
**Цель:** сообщения реально ходят между двумя устройствами.

Рекомендуемый путь (самый быстрый и честный):

1. Использовать существующие публичные SimpleX SMP-серверы + при желании поднять 1 свой.
2. Сделать минимально необходимый клиентский контур:
   - создание/загрузка identity (у нас уже есть Ed25519 + X25519);
   - создание очередей SMP;
   - отправка и получение сообщений;
   - подключение Double Ratchet поверх канала.

**Что должно появиться:**
- Реальный клиент, который умеет создать очередь, подписаться, отправить/получить.
- Интеграция с уже существующим `DoubleRatchetVault`.
- Простой экран крипто-чата (даже самый аскетичный — главное, чтобы работал).

**Критерий готовности фазы:**  
Два телефона обмениваются текстом «Привет, брат» → сообщение приходит зашифрованным и успешно расшифровывается.

---

### Фаза 2. Конфигурация реальных серверов
**Цель:** в приложении лежат рабочие адреса.

Сделать конфиг, в котором явно прописаны:

- 2–3 публичных SMP-сервера SimpleX;
- при желании — 1 свой;
- возможность переключения.

XFTP, сложный V2Ray/Reality и прочее на RC1 можно оставить в `[SIM]`.

---

### Фаза 3. Криптографическая обвязка чата
**Цель:** красиво связать уже существующие примитивы.

- Обмен Ed25519 public keys + fingerprint / SAS-эмодзи при установлении контакта.
- Инициализация Double Ratchet (initiator / responder).
- Каждое сообщение: 16 KB padding + AEAD + правильный ratchet step.

---

### Фаза 4. UX и честность для показа друзьям
**Цель:** чтобы при демонстрации не было стыдно.

- Чёткое разделение: нарды = фасад, скрытый режим = крипто-чат.
- Все оставшиеся симуляции помечены `[SIM]`.
- Простой онбординг для друга (установил → создал профиль → добавил собеседника → написал).
- Короткая инструкция «Как потестировать RC1».

---

### Фаза 5. Тестирование и фиксация RC1

Обязательные тесты:
1. Два устройства, разные сети.
2. Обмен ≥ 20 сообщениями в обе стороны.
3. Перезапуск приложения → сессия жива.
4. Padding на проводе работает.
5. Fingerprint / SAS сходятся.

После этого:
- версия `0.3.0-rc1`
- `RC1_RELEASE_NOTES.md`
- подписанный APK
- можно показывать кентам
