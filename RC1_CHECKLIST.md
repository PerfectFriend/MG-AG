# 🎯 MadGammon Definition of Done — RC1 (v0.3.0-rc1)

> **Статус**: В разработке  
> **Цель**: Состояние проекта, при котором крипто-чат реально работает между двумя независимыми устройствами через живые сервера, а симуляции честно отделены от рабочего ядра.

---

## ✅ Критерии готовности (DoD)

- [ ] **1. Чистый фундамент (Фаза 0)**
  - [x] Сила KDF поднята до 210k PBKDF2-HMAC-SHA256 (выполнено в v0.2.4)
  - [x] Честные Ed25519 & X25519 Identity Keys из BIP-39 (выполнено в v0.2.4)
  - [x] Исключение Firebase BOM из зависимостей (выполнено в v0.2.4)
  - [ ] Смена `applicationId` на `org.madgammon.app` (без временного суффикса)
  - [ ] Обновление документации честности `SIMULATION_AUDIT.md`

- [ ] **2. Живой транспорт сообщений SimpleX (Фаза 1 & 2)**
  - [x] Список реальных SMP-серверов (`smp10.simplex.im` ... `smp16.simplex.im`) в конфиге
  - [x] WebSocket SMP-клиент с поддержкой очередей (`NEW`, `SEND`, `LISTEN`, `ACK`)
  - [ ] Автоматический fallback: Direct ClearNet WSS при отсутствии запущенного локального Tor SOCKS5 демона
  - [ ] Простой сценарий соединения собеседников (обмен SMP Queue link / инвайтом)

- [ ] **3. Криптографическая обвязка чата (Фаза 3)**
  - [x] Double Ratchet сессии с постоянным размером конверта (16 KB padding) и AAD
  - [x] Зашифрованная локальная база сообщений (Room + Master PIN)
  - [ ] Автоматический обмен публичными ключами Ed25519/X25519 при установлении первого контакта

- [ ] **4. UX и сценарий проверки друзьями (Фаза 4 & 5)**
  - [x] Фасад нард + скрытый режим чата
  - [ ] Простая инструкция «Как проверить RC1 вдвоем»
  - [ ] End-to-end проверка: обмен сообщениями между 2 телефонами в разных сетях (Wi-Fi / 4G)
