# 🚀 ЗАДАЧА 05: ВЕРИФИКАЦИЯ, ТЕСТИРОВАНИЕ И ФИНАЛЬНАЯ СБОРКА РЕЛИЗНОГО APK

## 🎯 ЦЕЛЬ
Провести сквозную автоматическую верификацию всех криптографических и нативных модулей, прогнать юнит-тесты и собрать готовый установочный файл APK.

---

## 🛠️ ШАГИ ДЛЯ HERMES AGENT

### Шаг 1. Прогон Unit-тестов криптографического ядра
Выполни в терминале:
```bash
./gradlew testDebugUnitTest --info
```
Убедись, что все тесты проходят успешно (100% PASS):
- `ZeroKnowledgeVaultEngineTest` — проверка восстановления данных Рида-Соломона при потере 2 осколков из 6.
- `DoubleRatchetTest` — проверка работы цепочки ключей KDF и шифрования AEAD.
- `MentalDiceTest` — проверка криптографического броска костей Commit-Reveal.

---

### Шаг 2. Сборка Debug APK
Выполни в терминале:
```bash
./gradlew assembleDebug
```
В результате должен появиться файл:
`app/build/outputs/apk/debug/app-debug.apk`.

---

### Шаг 3. Инспекция нативных библиотек внутри APK
Убедись, что нативные библиотеки упакованы корректно и будут доступны для распаковки:
```bash
unzip -l app/build/outputs/apk/debug/app-debug.apk | grep -E "lib/arm64-v8a|lib/x86_64"
```
Ожидаемый вывод:
```text
lib/arm64-v8a/libtor.so
lib/arm64-v8a/libxray.so
lib/arm64-v8a/libhev-socks5-tunnel.so
lib/x86_64/libtor.so
lib/x86_64/libxray.so
lib/x86_64/libhev-socks5-tunnel.so
```

---

### Шаг 4. Проверка прав исполнения SELinux
На целевом Android-устройстве (или эмуляторе) после установки:
```bash
adb shell ls -la /data/app/*/lib/arm64/
```
Все библиотеки должны иметь атрибуты исполнения: `-rwxr-xr-x` или `-r-xr-xr-x`.

---

### Шаг 5. Финальный отчёт
Сформируй итоговый отчёт для разработчика:
1. Статус сборки APK и размер бинарника.
2. Список подтверждённых нативных библиотек в `jniLibs`.
3. Готовность к подключению к `.onion` узлам SMP и серверам XFTP.
